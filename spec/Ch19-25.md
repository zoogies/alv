## 24 Calls and Functions

### 24.1 Function Objects
- differ: `Obj::Function(Function)` where `Function { arity: u8, chunk: Chunk, name: Option<Box<str>> }`.
  `None` means the top-level script. The book's `ObjString* name` becomes an owned `Box<str>`.
- do: `printObject` cases become Display arms: `<fn name>`, `<script>`
- skip: `freeObject`

### 24.2 Compiling to Function Objects (the big refactor)
- differ: in the book, the per-function state is in `Compiler` and the parser stays global. Split your
  `Compiler` into:
  - outer struct: `scanner`, `parser`, `heap`, `states: Vec<FunctionState>`
  - `FunctionState`: `function: Function`, `fn_type: FunctionType`, `locals`, `scope_depth`
    (25.2 adds `upvalues`)
- differ: the outer struct has no chunk. Every chunk belongs to a `Function`, and the top-level
  program is one too (`<script>`, `name: None`). `compile` pushes that state as `states[0]`
  before parsing and pops it at the end. Delete the `chunk: &'c mut Chunk` field.
  `currentChunk()` returns `&mut` to `states.last_mut()`'s `function.chunk`, and `emit_byte`
  and the other emit fns go through it.
- differ: the book calls `newFunction()` up front and compiles straight into the heap object.
  Don't. A `&mut` into one heap object blocks `heap.alloc_string` while you compile. Build the
  `Function` inside `FunctionState`, then allocate it in `end_compiler`. The book only
  allocates early so the GC can see the function.
- do: `FunctionType { Function, Script }`
- 24.2.1 do: `compile` returns `Result<ObjRef, IError>` (in place of the book's `NULL`)
- 24.2.1 do: reserve slot 0 by pushing `Local { name: "", depth: Some(0) }`
- 24.2.1 do: `end_compiler` pops the state, allocates the function and returns the `ObjRef`.
  The disassembler header uses the function name, or `<script>`.

### 24.3 Call Frames
- differ: `CallFrame { function: ObjRef, ip: usize, slots: usize }`. The `ip` pointer becomes
  an index into the chunk, and `slots` becomes the frame's base index into the stack. The VM
  loses its `ip` and gets `frames: Vec<CallFrame>`. Keep `FRAMES_MAX = 64` as a check on
  `frames.len()`. `STACK_MAX` isn't needed with a `Vec` stack.
- 24.3.3 differ: the book caches `CallFrame* frame` as a local in `run`. In Rust you can't hold
  `&mut` to the frame while you touch `self.stack` or `self.heap`. Have `read_byte`,
  `read_short` and `read_constant` look up the top frame and its chunk on every call. They
  return Copy values, so no borrow outlives the call.
- 24.3.3 differ: the chunk now lives in the heap
  (`match self.heap.get(frame.function) { Obj::Function(f) => &f.chunk, _ => unreachable!() }`).
  Same rule as globals: never hold that `&Chunk` across a heap alloc (concat) or a
  `&mut self` call.
- 24.3.3 do: `GET/SET_LOCAL` index `frame.slots + slot`. `runtime_error` reads the line from
  the top frame.
- 24.3.3 do: `interpret` compiles, pushes `Value::Obj(f)`, and pushes a frame with `ip: 0, slots: 0`
- CHECKPOINT 1: every Ch. 21–23 script behaves identically. This is a pure refactor with no new features.

### 24.4 Function Declarations
- do: `fun_declaration`, `function(FunctionType)`; `mark_initialized` returns early at depth 0
- 24.4.1 differ: the `enclosing` linked list becomes `states.push` / `states.pop`.
  `initCompiler` = push, `endCompiler` = pop, and popping does the book's
  `current = compiler->enclosing` for you. After the pop, the function's `OP_CONSTANT` goes
  into the enclosing (now last) state's chunk.
- 24.4.2 do: parameters via `parse_variable` / `define_variable`, `arity += 1`,
  "Can't have more than 255 parameters."
- 24.4.2 differ: `copyString(name)` becomes `previous.lexeme.into()`. The function must own
  its name, since REPL source is dropped after each line.
- CHECKPOINT 2: `fun f(a, b) { print a; }` compiles, and `DEBUG_PRINT_CODE` shows the
  nested chunk. Calls don't work yet.

### 24.5 Function Calls
- do: compiler `call` as the infix rule on `LeftParen` at `Precedence::Call`. `argument_list`
  returns `u8`, with "Can't have more than 255 arguments.". Add `OP_CALL` and its disassembler
  case (byte instruction).
- 24.5.1 differ: `call_value` / `call` are VM methods. Borrow trap: `match self.heap.get(callee)`
  keeps `self.heap` borrowed for the whole match, so you can't call `self.call(..)` (`&mut self`)
  inside an arm. Copy what you need (arity, fn pointer) out of the match first, then call.
  Non-callable: "Can only call functions and classes."
- 24.5.1 do: new frame `slots = stack.len() - arg_count - 1`
- 24.5.2 do: "Expected {} arguments but got {}.", and "Stack overflow." at `FRAMES_MAX`
- 24.5.3 do: stack trace over `frames.iter().rev()`: `[line N] in name()` or `[line N] in script`
- 24.5.4 differ: `OP_RETURN` pops the result and then the frame. If no frames are left, pop the
  script and return `Ok`. Otherwise `stack.truncate(frame.slots)` (add this to `Stack`; it's
  the book's `vm.stackTop = frame->slots`) and push the result.
- 24.5.4 do: `emit_return` emits `OP_NIL` then `OP_RETURN`. `interpret` now uses `call(f, 0)`.

## 25 Closures

### 25.1 Closure Objects
- differ: `Obj::Closure(Closure)` where `Closure { function: ObjRef, upvalues: Vec<ObjRef> }`.
  The `Vec` replaces `ObjUpvalue**` plus `upvalueCount` (the book keeps the count redundantly
  only for the GC). Display delegates to the function.
- 25.1.1 do: `function()` emits `OP_CLOSURE` after `end_compiler`. Add the disassembler case.
- 25.1.2 differ: `CallFrame.function` becomes `closure: ObjRef`. Reaching the chunk is now two
  hops (closure → function → chunk). Optionally keep the function's `ObjRef` in the frame too,
  so it stays one hop.
- 25.1.2 do: `call` takes a closure. In `call_value`, the `Obj::Function` arm becomes
  `Obj::Closure`. `interpret` wraps the script in a closure (skip the GC push/pop).
- CHECKPOINT 5: everything from Ch. 24 still passes with every function wrapped in a closure

### 25.2 Upvalues
- 25.2.1 do: compiler `Upvalue { index: u8, is_local: bool }`, `upvalues: Vec<_>` in
  `FunctionState`, and `upvalue_count` on `Function` (the VM needs it to read `OP_CLOSURE`'s
  operands). `named_variable` tries local, then upvalue, then global. Add `OP_GET/SET_UPVALUE`.
- 25.2.2 differ: `resolveUpvalue` recurses on `compiler->enclosing`. With the `Vec`, recurse
  on an index instead: `resolve_upvalue(depth, name)`, where `depth == 0` (no enclosing) gives
  `None`, and `states[depth - 1]` is the enclosing state. `resolve_local` and `add_upvalue`
  need the same depth parameter. Pass indices, not `&mut FunctionState`s, so one call can
  touch two states.
- 25.2.2 differ: the book reads `compiler.upvalues` after `endCompiler`. Have `end_compiler`
  return the popped state's upvalues along with the `ObjRef`.
- 25.2.2 do: `OP_CLOSURE` takes variable-length `(is_local, index)` pairs. The disassembler
  loops over them.

### 25.3 Upvalue Objects
- differ: `Obj::Upvalue(..)` holding `enum { Open(usize), Closed(Value) }`. This replaces both
  `Value* location` and the `closed` field: open = a stack index, closed = the value itself.
  Rename one of the two `Upvalue` types (compiler vs heap) so they don't clash.
- 25.3.1 do: the `OP_CLOSURE` handler loops over the pairs. `is_local` means
  `capture_upvalue(frame.slots + index)`; otherwise copy the current closure's
  `upvalues[index]`. Build the whole `Vec` first, then allocate the `Closure`.
- 25.3.1 do: `GET_UPVALUE` matches `Open(slot)` → stack value, `Closed(v)` → `v`.
  `SET_UPVALUE` needs `heap.get_mut`.
- CHECKPOINT 6: closures that are called while their enclosing function is still running work

### 25.4 Closed Upvalues
- 25.4.2 do: `Local.is_captured`; `end_scope` emits `OP_CLOSE_UPVALUE` or `OP_POP`
- 25.4.3 differ: the book's `openUpvalues` is a linked list via `next`, sorted by descending
  stack address. Use `open_upvalues: Vec<ObjRef>` on the VM, sorted by slot ascending, so the
  stack top sits at the end. `capture_upvalue` scans from the end: reuse a matching slot,
  otherwise insert in order. Skip `ObjUpvalue.next`. `reset` clears the `Vec`.
- 25.4.4 differ: `close_upvalues(last)`: while the last entry's slot is `>= last`, switch it
  to `Closed(stack value)` via `get_mut` and pop it off the `Vec`.
  `OP_CLOSE_UPVALUE` = `close_upvalues(stack.len() - 1)` then pop.
  `OP_RETURN` = `close_upvalues(frame.slots)` before the truncate.
- CHECKPOINT 7: escaping closures (`makeCounter`), and two closures sharing one variable
