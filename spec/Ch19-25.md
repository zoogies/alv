# Ch. 19–25 plan (skipping 20, 26)

Heap: `Vec<Obj>`, `alloc`/`get`/`get_mut`, never frees. `ObjRef(u32)` is Copy and opaque.
No refcounting, no GC.

## 19 Strings
- 19.1  do: `Value::Obj(ObjRef)`
- 19.2  differ: `enum Obj { String(Box<str>) }`, so tag/casts/`isObjType` become `match`
- 19.3  differ: write heap.rs here. VM owns `Heap`, Compiler holds `&mut Heap`
- 19.4  do: print + equality (take `&Heap`), comparing contents
- 19.4.1 optional: concatenation (read, then alloc)
- 19.5  skip

## 20 Hash Tables
- skip. Globals: `FxHashMap<Box<str>, Value>` behind your own type

## 21 Global Variables
- 21.1  differ: `match` is a Rust keyword; name it e.g. `match_token` (as in treewalk)
- 21.1  do: print moves from `OP_RETURN` to `OP_PRINT`; hoist `VM` out of the REPL loop
- 21.2  differ: `globals: FxHashMap<Box<str>, Value>` keyed by contents, not `ObjRef`
  (no interning, so each identifier use is a fresh handle). Look up with `&str`
  (`Box<str>: Borrow<str>`), `clone()` only to insert. Inline in `run`: disjoint
  field borrows of `heap`/`globals` break if moved into a `&mut self` helper
- 21.2  do: `OP_DEFINE_GLOBAL` peek, store, then pop (matters once GC exists)
- 21.4  differ: no insert-then-`tableDelete`; `get_mut`, error if missing; keep the `peek`
- 21.4  do: parse fns take `canAssign: bool`; add early `return` after "Expect expression."
